# SYNCS HACKATHON 2026 MonGoats team
## MonGoats — Living Knowledge

Living Knowledge turns oral history clips into searchable, structured stories. Upload a voice or video recording in Mongolian, Japanese, or Russian, and it gets transcribed, translated into English, and summarized into a title, summary, and key points — automatically.

Built for SYNCS Hackathon 2026.

## Features

- Upload audio or video clips in Mongolian, Japanese, or Russian
- Automatic transcription (Chimege for Mongolian, ElevenLabs for Japanese/Russian)
- AI-generated title, summary, and key points via Gemini
- Search across all stored stories
- Playback of the original clip alongside its transcript and translation

## Tech stack

- Django 5.2, PostgreSQL (Supabase)
- Chimege, ElevenLabs, and Gemini APIs
- Deployed on Railway
